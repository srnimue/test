オトリヒキノート v0.10.6-preview

コードレビュー反映・安定性修正版

・localStorage保存失敗時に警告し、保存画面を勝手に閉じないよう改善
・並び替え保存 / インポート保存にも失敗時の保護を追加
・X ID入力を正規化（全角＠、x.com/、mobile.twitter.com、後ろのメモなどに対応）
・通常取引と長期取引の境界では並び替え矢印を無効化
・手渡し時間で全角数字に対応（１４００ → 14:00）
・時間エラーをalertではなく入力欄下のメッセージに変更
・フォームの取得範囲を編集ダイアログ内に限定
・書き出し時のObject URL解放を1秒遅らせ、iOSでの保存失敗を起きにくくした
・Archive表示中の検索でArchive外の取引が混ざらないよう修正
・空のorderを0として扱わないよう修正
・crypto.randomUUID未対応環境向けのID生成フォールバックを追加
・createdAtのない旧データに、読み込みのたび現在時刻を付け直さないよう修正

※イベント表示の日付/時間順ソート、インポートの「統合」は今回は未実装です。
