オトリヒキノート v0.10.0-preview

イベント表示の試作版です。

・画面タイトルを「オトリヒキノート」に変更
・通常表示 / イベント表示の切り替えを追加

・件数表示を「未受け渡し / 済み」に変更
・既存の「完了」をイベント表示では「済み」として扱う

・検索と「未受け渡し / 済み / すべて」絞り込みはそのまま利用可能
・データ項目は増やしていないため、既存データ形式は変更なし
・index.htmlを改行・インデント付きで読みやすく整理
