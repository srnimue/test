"1. キャッチコピー（ヘッダー）
お取引ノート

交換・譲渡・買取を、ひとまとめに。
X（旧Twitter）でのグッズやお取引の進行状況を、シンプル＆安全に管理できるWebアプリです。

2. このアプリの特徴
個人情報なしで安全

名前や住所の入力欄はありません！アカウントIDと進捗だけをスマートに管理できます。

通信なし・完全ローカル保存

入力したデータがサーバーに送信されることは一切ありません。お使いのスマホ（ブラウザ）内だけに保存されます。

バックアップ機能つき

データの「書き出し（エクスポート）」と「読み込み（インポート）」に対応。端末の変更や万が一のときも安心です。

アプリインストール不要

ブラウザで開くだけで今すぐ使えます。

3. 基本的な使い方
「+ 新しい取引」をタップ

相手の表示名、X ID（@xxx）、取引種別（交換/譲渡/買取）、お品物を入力して登録します。

ステータスを更新する

取引が進んだら「DM確認中」「発送待ち」「完了」などを切り替えるだけ！
一目で状況がわかる絵文字バッジ（🏠住所済 💵入金済 など）や、発送方法のワンタップ入力（[普通郵便] など）でサクサク入力できます。

進行中と完了を自動で整理

普段は「進行中」の取引だけが表示されるので、今やるべきことが一目でわかります。完了した取引は「完了」タブからいつでも確認可能です。"
