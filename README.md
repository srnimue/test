# お取引ノート
**交換・譲渡・買取を、ひとまとめに。**

X（旧Twitter）でのグッズやお取引の進行状況を、シンプル＆安全に管理できる無料のWebアプリです。
面倒な登録やアプリインストールは不要。ブラウザで開いてすぐ使えます。

---

### 📖 基本的な使い方

1. **取引を登録する**
   「+ 新しい取引」をタップし、相手の表示名・X ID（@xxx）・取引種別（交換/譲渡/買取）・品名を入力します。
   ※ 発送方法のクイック選択チップや、手渡し/郵送の切り替えも可能です。

2. **進捗に合わせてステータスを切り替える**
   「DM確認中」「発送待ち」「完了」などをワンタップで更新！
   住所交換済み（🏠）や支払い済み（💰）のチェックを入れると、一覧カードにも絵文字バッジが表示されて一目で進捗がわかります。

3. **完了した取引を整理する**
   普段は「進行中」の取引だけが表示されるので、今やるべき作業に集中できます。
   完了した取引は「完了」タブや「Archive」へ移動してスッキリ整理！

4. **ホーム画面に追加してアプリ化**
   スマホのブラウザメニューから「ホーム画面に追加」を行うことで、ネイティブアプリ感覚でワンタップ起動できます。

---

## 💡 4つの安心・便利ポイント

1. **個人情報は一切不要**
   名前や住所などの個人情報入力欄はありません。XのアカウントIDと取引内容・進捗だけをスマートに管理します。

2. **通信なし・完全ローカル保存**
   入力したデータが外部サーバーに送信されることは一切ありません。すべてお使いの端末（ブラウザ）内だけに安全に保存されます。

3. **完全無料・広告なし**
   画面を邪魔する広告はありません。快適で爆速な操作感にこだわりました。

4. **バックアップ・データ移行対応**
   「データの書き出し（JSON）」と「読み込み」に対応。機種変更や万が一のキャッシュ削除時も安心です。


### ⚠️ ご利用上の注意
* ブラウザの履歴・キャッシュを全削除すると保存データも消えてしまうため、定期的な「データの書き出し（バックアップ）」をおすすめします。
* 推奨環境：iOS (Safari) / Android (Chrome) 各最新版
